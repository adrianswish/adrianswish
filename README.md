## How I work

These are not slogans. They are the rules the repos are built under. If a house breaks one, it is not done.

### 1. Houses do not merge

Open Hood is not Compton One. Label IQ is not the music platform. First Bucket is not a sports OS. Each product keeps its own repo, its own stack, its own failure mode, its own live URL.

I do not fold two businesses into one codebase because I own both. A civic receipt does not belong in a VIN decoder. An album campaign does not belong in a pack scanner. When a house is ready, it ships as itself.

Private houses stay private. They are named on this page only when they have a sanctioned still. They never get a GitHub link from here.

### 2. Fail closed

If the number is missing, the product refuses. It does not guess. It does not fill the hole with a default. It does not show a green check on a blank.

Open Hood will not invent a spec from a bad VIN. Compton One will not send you down an unverified path. Honest Aisle will not score a pack it cannot read. AIO.GEO will not claim a place is visible if it cannot prove what the model saw.

A missing value is a stop. The stop is the feature.

### 3. Receipts, not vibes

Every house that matters has something you can hold: a walk URL, a civic receipt, a stamped sheet, a pack score, a geo proof.

I do not ship “AI-powered” as the product. The product is the artifact the user walks away with. If you cannot point at the receipt, the house is still a demo.

Live, demo, private, hold — those stamps are honest. A screenshot is not a live product. A login door is not a dashboard. This page will not say live unless the URL is public and working.

### 4. Humans stamp money

Agents draft. People send, pay, and publish.

Anything that moves money, identity, or a public claim has a human in the loop. The model does not hit send. The model does not mark a royalty paid. The model does not publish a civic path as official.

That is HITL as a product rule, not a safety slide. If the path can cost someone real money or real standing, a person stamps it.

## Stack

What I actually write with. Not a badge wall.

**Languages.** TypeScript first. JavaScript where the runtime is. Python for protocols, scoring, and tools. SQL at the data layer. C when the house is an instrument or a native plugin (CLAP / VST3 / AU).

**App.** React 19. Next.js 15–16. TanStack Start / Router / Query when the house needs a real client spine instead of a page router. Vite. Expo when it has to be a phone.

**Server & data.** Node. NestJS on the heavier APIs. Postgres. Prisma. Supabase or Neon where the house needs auth + storage without standing up a second company.

**Hard surfaces.** WebGL (foil, packs, game). AudioWorklet + Icecast (live audio). OCPP 2.1 (charge). Playwright for the walk, not just the unit.

**Ship.** pnpm. Turborepo on the monorepos. Vercel or Cloudflare for the public URLs. npm for the one published CLI (`@aio-geo/cli`). GitHub Actions when the house has a test that must run on every push.

I am not a ten-year staff engineer. I am a founder who writes and builds the product end to end — schema, UI, the fail-closed path, the live URL — and I will not claim a stack I have not shipped.
